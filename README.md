# 🍬 Balaji Sweets Shop - Revenue Generation Project

A full-stack web application developed in the 6th semester using **Laravel** and **PHP**, aimed at managing both the user and admin side of a sweets shop. This project showcases a revenue-generating online platform for sweets ordering and inventory control.

---

## 🛠 Features

- User Registration & Login
- Browse sweets by category
- Add items to cart and checkout
- Admin Panel:
  - Add/Edit/Delete products
  - View orders
  - Track revenue
- Order history
- Inventory management
